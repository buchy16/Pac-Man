# Cheats

Pendant la partie, utilisez la touche `[F3]`pour activer/désactiver le mode `cheat`.

Si besoin, saisissez `help` pour accéder au manuel des commandes de cheat :

+ `help` :  
	*Display all command manual*

+ `kill` :  
	*Kill the player*

+ `skip-level` :  
	*Skip the curent level*  
	It may be a good idea to run `freeze all` before this `skip-level` command, to stop Pacman from taking advantage of the animation to eat ghosts ;)

+ `reset-all` :  
	*Reset all ghosts and set their position back to their respective corner*

+ `lives <nb lives>` :  
	*Change player's life value*

+ `score <score value>` :  
	*Change player's score value*

+ `speed <speed value/reset>` :  
	*Change player's speed,*  
	par ex : `speed 0.5` = vitesse x2 ; `speed 2` = vitesse /2

+ `freeze <all/ghost's name> <true/false>` :  
	*Activate/desactivate Freeze ghosts (they can't move)*  
	Ghosts's name : `pinky`, `blinky`, `inky` and `clyde`

+ `invincible <true/false>` :  
	*Set if the player can be hit by ghosts*

+ `stop-timer <true/false>` :  
	*Stop the timer or not*

+ `super <true/false>` :  
	*Set Pacman to super Pacman or not*

Pour rappeler la derniére commande, utilisez la touche [tab] : les 6 dernières commendes sont gardées en mémoire.

**Exemples** d'utilisation :  
- `freeze blinky true` : Blinky se drape de **blanc** et **s'immobilise** (les autres continuent) ;
- `invincible true` : Pacman peut entrer en collision avec un fantôme sans perdre de vie ;
- `super true` : tous les fantômes se drapent de **bleu**, ralentissent et s'éloignent de Pacman comme s'il avait mangé une super-pacgum;
- `reset-all` : tous les fantômes retournent à leur coin de départ.
